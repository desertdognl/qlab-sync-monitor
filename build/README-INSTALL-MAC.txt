QLab Sync Monitor - macOS install steps

If macOS blocks the app with a security warning:

1. Open the DMG and drag "QLab Sync Monitor.app" to Applications.
2. Open System Settings -> Privacy & Security.
3. Scroll to Security and click "Open Anyway" for QLab Sync Monitor.
4. Confirm by clicking "Open".

Alternative first-run method:
- In Finder, Control-click the app and choose "Open", then confirm "Open".
